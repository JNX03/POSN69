# บวกเลขสองจำนวน - โปรแกรมตรวจตัวอย่าง

ให้เขียนฟังก์ชัน `addTwo` ในไฟล์ `add_two.cpp` และเก็บไฟล์ `add_two.h` ไว้โดยไม่แก้ไข ไม่ต้องเขียนฟังก์ชัน `main` ไม่ต้องอ่านข้อมูลจากอินพุตมาตรฐาน และไม่ต้องพิมพ์ข้อมูลไปยังเอาต์พุตมาตรฐาน

## คอมไพล์และรัน

```sh
sh compile.sh
./add_two < sample/sample1.in
```

ผลลัพธ์ต้องตรงกับไฟล์ `sample/sample1.out` (เปรียบเทียบแบบไม่สนช่องว่างท้ายบรรทัด)

## รูปแบบอินพุตของโปรแกรมตรวจ

- บรรทัดแรก: Q จำนวนครั้งที่เรียกฟังก์ชัน
- แต่ละบรรทัดมีจำนวนเต็ม a และ b คั่นด้วยช่องว่าง

ค่าที่ฟังก์ชันคืนกลับ บรรทัดละหนึ่งค่า
